# Spring Learning

My hands-on journey learning the Spring ecosystem for Java backend development.

## 📚 Reference

This repository follows **[Spring Start Here, 2nd Edition](https://www.manning.com/books/spring-start-here)** as the primary reference for learning Spring.

The examples and exercises are implemented by me while working through the book, with additional experimentation where useful.

## 🚀 Topics

- Spring Core
- Spring Boot
- Spring Data
- Spring Security
