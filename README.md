# Spring Learning

Hands-on code from working through **[Spring Start Here, 2nd Edition](https://www.manning.com/books/spring-start-here)** (MEAP).

✅ **Status: Completed.** I finished every chapter available in the MEAP (chapters 2-10). Examples are implemented by me.

## 🚀 What's Covered

- **Spring Core**: creating beans, wiring with `@Autowired`, interfaces and dependency injection, bean scopes, aspects
- **Spring MVC**: building a web app, request/session/application scopes
- **REST**: building REST endpoints
